# 🛗 Lift Moving Simulation

> A real-time elevator movement simulation built using JavaScript logic and interactive UI controls.

🔗 Live Demo: https://huzaifaliftmover.netlify.app/  
🔗 GitHub Repo: https://github.com/HuzaiFaRz/Lift-Moving  

---

## 📌 Project Overview

This project simulates a real elevator system where the lift moves between floors based on button input.

---

## ✨ Features

- Interactive floor buttons
- Dynamic lift movement animation
- Real-time floor detection logic
- Smooth transition effects
- Responsive layout

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

---

## 🎯 Learning Outcomes

- Logical state management
- Movement calculation algorithms
- Animation timing control
- Event-driven programming
